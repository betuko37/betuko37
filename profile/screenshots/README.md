# Screenshots del portafolio

Imágenes sanitizadas para el README de perfil.

## Cómo reemplazar placeholders

1. Toma capturas **sin datos reales** (nombres, rostros, RFCs, montos sensibles, ubicaciones GPS).
2. Guarda PNG/JPG/WebP en la carpeta del proyecto.
3. Actualiza las rutas en `README.md` raíz si cambias el nombre del archivo.
